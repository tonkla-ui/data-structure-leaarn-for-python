ด่านที่ 1 · ดินแดนแห่งตัวอักษร

String สายอักขระ

ทุกถ้อยคำในโปรแกรมล้วนเริ่มจากที่นี่ — ลำดับของตัวอักษรที่เรียงต่อกันอย่างมีวินัย และไม่ยอมให้ใครมาแก้ไขค่าเดิม

📜 ตำราประจำด่าน

  • เรียงลำดับ (Ordered): ตัวอักษรแต่ละตัวมีตำแหน่ง index ที่แน่นอน เริ่มนับจาก 0
  • แก้ไขค่าไม่ได้ (Immutable): เมื่อสร้าง string แล้ว จะไปเปลี่ยนตัวอักษรตัวใดตัวหนึ่งโดยตรงไม่ได้
  • ดัชนีติดลบ (Negative index): ใช้ -1 เพื่อนับจากท้ายสุดย้อนกลับมา
  • Slicing: ใช้ s[start:end] เพื่อตัดข้อความช่วงหนึ่งออกมา (ไม่รวมตำแหน่ง end)
  • สร้างด้วยเครื่องหมายคำพูด "..." หรือ '...'

List รายการ

กล่องเก็บของที่เรียงเป็นแถว เปิดให้คุณสลับ เพิ่ม หรือลบของข้างในได้ตลอดเวลา

📜 ตำราประจำด่าน

  • เรียงลำดับ (Ordered): มี index เหมือน string เข้าถึงด้วย list[i] ได้
  • แก้ไขค่าได้ (Mutable): เปลี่ยนค่า เพิ่ม หรือลบสมาชิกภายหลังได้ด้วย append(), remove()
  • มีค่าซ้ำได้: ใส่สมาชิกที่มีค่าเหมือนกันหลายตัวได้
  • สร้างด้วยวงเล็บเหลี่ยม [ ]

🔍 ภาพประกอบ

ก่อนแก้ไข
apple
banana
cherry
fruits[1] = "mango"
➜
หลังแก้ไข
apple
mango
cherry
index [1] ถูกเขียนทับได้โดยตรง — นี่คือความหมายของ mutable

💻 ตัวอย่างโค้ด

fruits = ["apple", "banana", "cherry"]
fruits[1] = "mango"       # แก้ไขค่าตำแหน่ง 1
fruits.append("kiwi")     # เพิ่มท้ายรายการ
print(fruits)
→ ['apple', 'mango', 'cherry', 'kiwi']

⚔️ ภารกิจย่อย

1) จากโค้ด fruits[1] = "mango" ผลลัพธ์ของ print(fruits) คือ?

2) List เป็นทั้งชนิดข้อมูลที่ เรียงลำดับ และ แก้ไขค่าได้ — ถูกหรือผิด?

ด่านที่ 3 · ห้องนิรภัยแห่งข้อมูล

Tuple ทูเพิล

เหมือน list ทุกประการ แต่ถูกล็อกไว้ด้วยกุญแจ — เหมาะกับข้อมูลที่ไม่อยากให้ใครมาแตะต้อง

📜 ตำราประจำด่าน

  • เรียงลำดับ (Ordered): เข้าถึงด้วย index ได้เหมือน list
  • แก้ไขค่าไม่ได้ (Immutable): เมื่อสร้างแล้ว ห้ามเปลี่ยน เพิ่ม หรือลบสมาชิก
  • มีค่าซ้ำได้ เหมือน list
  • สร้างด้วยวงเล็บกลม ( )
  • นิยมใช้เก็บข้อมูลที่ตายตัว เช่น พิกัด (x, y) หรือค่าคงที่

🔍 ภาพประกอบ

10🔒
20🔒
point = (10, 20)
⚠️ point[0] = 99 → TypeError: 'tuple' object does not support item assignment

💻 ตัวอย่างโค้ด

point = (10, 20)
print(point[0])
→ 10

point[0] = 99       # ❌ TypeError: แก้ไขค่าไม่ได้

⚔️ ภารกิจย่อย

1) จากโค้ด point = (10, 20) คำสั่ง point[0] = 99 จะเกิดอะไรขึ้น?

2) ควรเลือกใช้ tuple แทน list เมื่อใด?

ด่านที่ 4 · ทะเลฟองสบู่แห่งความไม่ซ้ำ

Set เซต

ฟองสบู่ลอยอย่างอิสระไม่มีลำดับ และไม่มีวันมีฟองซ้ำกันสองใบ — ใครพยายามเติมของซ้ำจะถูกเด้งกลับ

📜 ตำราประจำด่าน

  • ไม่มีลำดับ (Unordered): ไม่มี index จะเรียก colors[0] ไม่ได้
  • แก้ไขได้ (Mutable): เพิ่มด้วย add() หรือลบด้วย remove() ได้
  • ไม่มีค่าซ้ำ: ถ้าเพิ่มค่าที่มีอยู่แล้ว จะไม่มีอะไรเกิดขึ้น
  • สร้างด้วยปีกกา { } หรือ set()

🔍 ภาพประกอบ

redgreenblue
colors.add("red") ❌ ซ้ำ — ไม่มีอะไรเปลี่ยน
colors.add("yellow") ✅ ใหม่ — เพิ่มเข้าไป

💻 ตัวอย่างโค้ด

colors = {"red", "green", "blue"}
colors.add("red")      # มีอยู่แล้ว ไม่เพิ่มซ้ำ
colors.add("yellow")   # ใหม่ เพิ่มเข้าไป
print(colors)
→ {'red', 'green', 'blue', 'yellow'}  # ลำดับไม่แน่นอน

⚔️ ภารกิจย่อย

1) จาก colors = {"red","green","blue"} หลัง colors.add("red") เซตจะมีสมาชิกกี่ตัว?

2) เราสามารถเข้าถึงสมาชิกด้วย colors[0] ได้หรือไม่?

ด่านสุดท้าย · หอสมุดแห่งกุญแจ-คำตอบ

Dictionary พจนานุกรม

ทุกคำตอบมีกุญแจของตัวเอง — เสิร์ชด้วย key แล้วรับ value กลับมาได้ทันที ไม่ต้องนับตำแหน่ง

📜 ตำราประจำด่าน

  • เก็บแบบคู่ key-value: แต่ละ key ต้องไม่ซ้ำกัน (แต่ value ซ้ำกันได้)
  • เรียงตามลำดับที่ใส่เข้าไป (ตั้งแต่ Python 3.7 เป็นต้นมา)
  • แก้ไขได้ (Mutable): เพิ่ม/แก้ไขค่าได้ผ่าน key โดยตรง
  • เข้าถึงค่าไม่ใช้ index แต่ใช้ d[key]
  • สร้างด้วยปีกกา { key: value }

🔍 ภาพประกอบ

"name"➜"Tonka"
"age"➜22
"grade"➜"A"
student["age"] ถูกแก้จาก 21 → 22 และเพิ่มคีย์ "grade" ใหม่

💻 ตัวอย่างโค้ด

student = {"name": "Tonka", "age": 21}
student["age"] = 22        # แก้ไขค่าเดิม
student["grade"] = "A"     # เพิ่ม key ใหม่
print(student["age"])
→ 22

⚔️ ภารกิจย่อย

1) หลัง student["age"] = 22 คำสั่ง print(student["age"]) จะได้อะไร?

2) Dictionary เก็บข้อมูลในลักษณะใด?
